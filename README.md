## Descripción
API RESTful para la gestión de Tareas y Categorías, construida con ASP.NET Core Web API, Entity Framework Core y SQL Server. Permite realizar operaciones CRUD, validar datos de entrada y manejar códigos de estado HTTP (201, 400, 404).
